# Навигация по приложению

Мини-карта интерфейса: где что лежит, что редактируется, а что только читается.

## Общее устройство

- **Сайдбар слева** — три сворачиваемые группы: **Data Room**, **Параметры**, **Отчёты**. Заголовок группы кликабелен (скрыть/показать пункты), состояние запоминается. Кнопка «‹» внизу сайдбара схлопывает его до узкой полосы иконок; на мобильном меню открывается бургером.
- **Шапка справа** — управление всей моделью:
  - **Сценарий** — переключатель Conservative / Base / Aggressive. Меняет векторы загрузки и экономические ручки сразу во всех отчётах.
  - **JSON** — выгрузка полного состояния модели (params + сценарии + сметы) в файл.
  - **Excel** — экспорт расчёта в .xlsx для проверки/рассылки.
  - **Загрузить** — импорт ранее выгруженного JSON.
  - **Сбросить** — все параметры к дефолтам `params.json` (с подтверждением).
  - **ИИ** — панель ИИ-консультанта: видит живые числа модели, отвечает по текущему сценарию; значок с цифрой = закреплённые ячейки.
- **Адресная строка** — hash-роутинг `#/dashboard`, `#/assumptions` и т.д.: вкладка переживает F5, ссылку можно переслать.
- **Подсказки** — иконка «?» у полей и строк отчётов: формула или пояснение «как считается эта цифра». У многих строк показан прямой расчёт («158 слот × €500 = €79 000»); формулы в документах рендерятся через KaTeX: $\mathrm{NPV} = \sum_t \frac{CF_t}{(1+r)^t} - I_0$.

## Параметры

Всё, что можно редактировать. Изменения мгновенно пересчитывают модель и сохраняются в браузере (localStorage).

### Допущения `#/assumptions`

Главный пульт модели — ~20 блоков в две колонки:

- **Общие** — инфляция, ставка дисконтирования (CAPM по компонентам: rf, β, ERP, страновая и size-премии — или ручной WACC), терминальная стоимость (выкл / Gordon growth).
- **Режимы** — гросс/с возмещением, мультипликатор спроса услуг.
- **Налоги и взносы** — НДС (стандартный, глэмпинг, F&B, входной), взносы работодателя, потолок GESY, периодичность CIT.
- **Распределение прибыли** — партнёры и доли, режим дивидендов (резидент/Non-Dom).
- **Амортизация** — доли и сроки по группам активов.
- **Прочие OPEX** — эквайринг, ремонт/обслуживание, маркетинг (min + % выручки), страхование.
- **Опциональные слои выручки** — у каждого тогл, по умолчанию **выкл**:
  - **Членства клуба** — цены месячного/годового, визиты, гости в визите, вытеснение слотов, сервисный чек.
  - **Сертификаты и пре-сейл** — цена и темп продаж, погашение/гости, окно пре-сейла, режим признания (предоплата / доп. канал).
  - **F&B** — food-cost, оклад и ставки повара.
  - **Глэмпинг** — число малых/больших юнитов, тарифы, доля OTA и комиссия.
- **Прачечная** — аутсорс vs своя (своя добавляет CAPEX оборудования ~€8k, но цикл дешевле).
- **Земля** — аренда участка.
- **Депозит и кошелёк услуг** — пакетный режим продаж.
- **Pre-opening** — расходы до открытия + тогл потока.
- **Maintenance CAPEX и стройка** — график стройки (S-кривая), капремонт.
- **Сезонность** — 12 помесячных множителей спроса (среднее = 1.000).
- **Модули бань** — 7 модулей: для каждого дата ввода, гостей/слот, слот/день (3), цены утро/день/вечер, статус (оч. 2 — включается пообъектно).
- **Очередь 2 — стройка и финансирование** — окно стройки, буфер CAPEX, отток, рампа, схема funding.
- **Общественный банный комплекс (оч. 2)** — билеты, ёмкость, тогл.
- **Ресторан (оч. 2)** — плейсхолдер-поток: места, обороты, чек.

### Сценарии `#/scenarios`

Матрица из трёх колонок (Conservative / Base / Aggressive), редактируется по ячейкам:

- **Векторы загрузки по годам** (годы 1–5, год 6 = год 5) — для каждого потока: модули бань, услуги (парение, массаж, доп.услуги), общественная баня и ресторан оч. 2, месячные членства (в людях).
- **Экономика** — рост цен, буфер CAPEX оч. 1, рампа выхода на план, доля реализации услуг (в пакетном режиме зафиксирована на 100%).
- **Стрессы** — задержка стройки (сдвигает открытие, растягивает CAPEX и аренду), множитель энергозатрат.

### Штат `#/staff`

Штатная таблица: 9 ролей (пармастер, массажист, администратор, хаусмен, управляющий, бронист, клинер, инженер, помощник пармастера) + условные (повар при вкл. F&B, IT-куратор). Оклады €/мес, ставки по фазам (старт / 2029-01 / 2031-01 / 2032-01), фонды на старт и при полном штате, со взносами.

### Номенклатура `#/nomenclature`

Справочник материалов и расходников (NC-коды): цена, доставка, нормы расхода на услуги/циклы. Источник себестоимости услуг и переменных OPEX.

### Смета стройки `#/smeta`

WBS строительства по очередям (вкладки «Очередь 1 / 2»): разделы → позиции с количеством, ценой, суммой. Поиск по тексту, сворачиваемые разделы, итоги по очередям.

### Смета закупа `#/zakup`

CAPEX-наполнение: оборудование, текстиль, инвентарь — по очередям (те же вкладки). Позиции со спековым расходом (цикл стирки и т.п.) здесь не показываются — они в номенклатуре/OPEX.

### Спецификации `#/specs`

Каталог услуг по направлениям (парения, массажи, доп.услуги): цена, ёмкость, состав услуги из позиций номенклатуры — то есть себестоимость каждой услуги «в разрезе».

### IT `#/it`

IT-контур: режим (IT-куратор в штате / аутсорс), содержание €/мес (хостинг, телефония, MSP, SaaS, маркетинг, домены, резерв), внедрение CAPEX (POS/ПК, кастомный слой, внедрение/обучение, сеть/WiFi/видео).

## Отчёты

Помесячные результаты расчёта. Редактируется только просмотр (фильтры/развороты); цифры следуют за параметрами и сценарием.

### Дашборд `#/dashboard`

- **KPI-карточки**: NPV, IRR, окупаемость и дисконтированная окупаемость (мес), MOIC, денежная доходность, пиковая потребность в финансировании, взносы акционеров, точка безубыточности, NPV+TV, инвестиции очередей 1 и 2.
- **Графики**: выручка по потокам, денежный поток и окупаемость, EBITDA и чистая прибыль — помесячно по всему горизонту.

### Выручка `#/revenue`

KPI-чипы (загрузка бань, проданные слоты) + помесячная таблица потоков. Строки с «▾» раскрываются в составляющие: слоты по модулям и времени суток, аренда по каждому модулю, парения/массаж/доп.услуги по позициям меню, глэмпинг по юнитам, членства/сертификаты, F&B, общественная баня, ресторан.

### OPEX `#/opex`

Помесячные операционные затраты: постоянные (+аренда земли), IT/АСУ, переменные (по номенклатуре — расходники услуг, стирка), комиссии эквайринга и OTA.

### ФОТ `#/fot`

Фонд оплаты труда помесячно: оклады по фазам набора персонала, взносы работодателя (с потолком GESY), итоги.

### CAPEX `#/capex`

Инвестиции помесячно: стройка по очередям (по S-кривой графика), наполнение/закуп, IT-внедрение, земля, pre-opening, maintenance CAPEX.

### Налоги `#/taxes`

НДС (начисленный/входной/к уплате), корпоративный налог 15%, взносы на ФОТ, дивиденды и SDC/GESY по партнёрам.

### P&L `#/pnl`

Отчёт о прибылях и убытках помесячно: выручка → переменные → валовая прибыль → постоянные+ФОТ → EBITDA → амортизация → EBIT → налоги → чистая прибыль.

### Cash-Flow `#/cashflow`

Движение денег помесячно: операционный, инвестиционный (CAPEX по очередям), финансовый (взносы акционеров, дивиденды) потоки; касса на конец месяца и дефицит финансирования.

### Sensitivity `#/sensitivity`

Чувствительность результата к параметрам — реальный пересчёт модели, не интерполяция:

- **Tornado** — топ-драйверы NPV.
- **Теплокарты**: спрос × WACC → NPV (и диск. окупаемость); рост цен × буфер CAPEX → NPV (IRR); доля пакетных гостей × загрузка; задержка стройки × буфер CAPEX; уровень всех цен → NPV (IRR).
