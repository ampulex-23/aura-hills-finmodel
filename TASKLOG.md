# Журнал задач

Краткая хроника внесённых изменений. Формат: дата — что сделано — коммит.

## 2026-10-14

- **Живая смета услуг (Вариант B).** Убран дубль `params.procedures`: выручка
  парений/массажей/допов теперь считается из живых спецификаций — `spec.price` +
  новое поле `spec.weight` (доля в меню направления). Объёмы привязаны к коду
  спеки, не к позиции: удаление услуги убирает её из выручки, COGS и KPI —
  объёмы больше не «перескакивают» на соседнюю позицию. Удалённая позиция
  номенклатуры вычищается из составов спек. Мёрж сохранённого состояния — по
  `code`, версия стора 7. Коммиты `e8a9337`, `75cfcea`; задеплоено,
  веса в прод-данных мигрированы вручную (`/srv/aura-hills-data` @ `4239200`).
- **Data Room «Генплан».** Раздел показывает артефакты `bim-as-code`:
  план, изометрия, таблица зданий из `spec.json`, скачивание IFC/GLB,
  футер с провенансом (коммит + время сборки). Пайплайн: `git push vds` →
  post-receive → сборка на сервере → `/srv/genplan/` → nginx `/genplan/`.
  Коммиты web `6e90ff2`, bim `5abf1f0`+; задеплоено.
- **Допущения: постоянные OPEX.** Все 9 статей `opexFixed` редактируются
  таблицей (название, €/мес, механика) — раньше UI давал только маркетинг
  и страхование. Коммит `53ef6fd`.
- **OPEX: количество списанной номенклатуры.** В раскрытых позициях
  переменных расходов клетка показывает количество под суммой
  («435 € / 12 шт») — как у аренды видны слоты в подсказке, теперь qty
  видно прямо в таблице.
- **Выручка: гости по модулям.** В «Слоты (шт)» и «Аренда бань» у строк
  модулей клетка показывает гостей под значением (слоты × вместимость) —
  раньше число гостей было только в нижней строке «гостей чайной зоны».
- **Выручка: количество процедур.** У строк спек (Парения / Массаж /
  Доп.услуги) под суммой показывается число проданных процедур
  (`serviceCounts` по коду спеки).
- **ФОТ: количество процедур под KPI-бонусами.** Новое поле
  `FotMonth.procCount` — сумма процедур по спекам с трудовой долей;
  в строке «KPI бонусы» под суммой показывается «N проц.»
- **OPEX-входы: закрыты дыры редактирования.** opexFixed — добавление/
  удаление статей («+ Статья», ✕); it.opex и it.capex — добавление/
  удаление строк + редактируемые названия; ownPrice (себестоимость
  при своей прачечной) — колонка «Прач. €» в Номенклатуре при включённой
  прачечной + поле в модале позиции.
- **Штат: график и покрытие смен.** Новое поле `fot.schedule` («2/2»,
  «5/2», «по записи» — справочно, редактируется) + колонка «На смене»:
  ставки × раб.дни/(раб.+вых.) — видно, сколько человек одновременно
  на смене. На фонд не влияет.
